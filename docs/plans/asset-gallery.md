# Asset galleries

**Program:** A1 Discovery (visibility + role sources).  
**Hub:** [`README.md`](README.md).  
**Status:** Model live; still gallery is the first specialization.

## Intent

An **asset gallery** is a corpus surface for browse / select / launch. **Starter**
is a **role** (seed / guide / reference), not a file-type enum.

Specializations include stills (UI today), clips, starter videos, workproduct-as-
starter, and later specialty sources (identity, pose, look for VACE / A4).

## Today
